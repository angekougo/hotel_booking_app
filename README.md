# hotel_booking_app

> **Projet Flutter — App multi-écrans avec navigation**
> Projet certifiant réalisé dans le cadre du *FlutterFire Summer Camp 2026*
> dans le but de valide ma maîtrise des widgets Flutter et de la navigation en construisant une app complète.

> Ce projet est validé avec un score ≥ 70/100 pour obtenir ta certification et débloquer les cours suivants.


> **Instructions**

> Construis une application Flutter multi-écrans sur le thème de ton choix (recettes, films, voyages, etc.).

> **Fonctionnalités obligatoires :**

> Au moins 4 écrans distincts
> Navigation avec GoRouter ou Navigator 2.0 (routes nommées)
> Un écran de liste avec recherche/filtrage
> Un écran de détail avec passage de paramètres
> Un formulaire avec validation (au moins 3 champs)
> Gestion du thème clair/sombre

> **Exigences techniques :**

> Utiliser au moins 8 widgets différents (ListView, GridView, Stack, Card, etc.)
> Créer au moins 3 widgets réutilisables dans un dossier `widgets/`
> Responsive : s'adapter à mobile et tablet
> Aucune donnée hardcodée dans les widgets (séparation UI/données)
> Livraison : repo GitHub public avec README, captures d'écran et instructions de lancement.

---

**L'idée du projet**
*Pour ce projet nous avons une une application de réservation de chambres d'Hotéls.*
*Cette application comporte:*
*- Un Onboarding de 3 écrans*
*- Un écran de login et Signup*
*- Un écran d'accueil*
*- Un écran de recherche*
*- Un écran de détails*

## Prérequis

**Dart SDK version: 3.6.2 (stable)**
**Flutter 3.27.4**

**Cloner le projet**
```git clone https://github.com/angekougo/hotel_booking_app.git```

```cd hotel_booking_app```

**Get packages**
```dart pub get```

## Lancement de l'application

```flutter run```
